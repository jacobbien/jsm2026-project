# The JSM program as a data frame

The JSM program as a data frame

## Usage

``` r
talks
```

## Format

A data frame where each row is a talk and with the following variables:

- session_number:

- session_title:

- session_type:

- day:

  The day

- start_time:

- end_time:

- author:

  The name(s) of the author(s). Names separated by commas.

- speaker:

  The name of the speaker. In rare cases where there are multiple
  speakers, their names are separated by commas.

- title:

  The talk title

- room:

- chair:

## Source

This data was scraped from the JSM website.
